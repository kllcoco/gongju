# 2026-11-11 修复记录

## 已修复或新增

- 拆分 PE 格式检查和手动映射能力检查。普通加载后的卸载不再因合法静态 TLS 或延迟导入被错误拒绝；用原版 Hook 的实际 8 字节 TLS 和 prepare 导出做解析回归。
- 普通卸载按规范化后的完整路径找模块，避免同名 DLL 导致卸载错误对象。
- TLS 目录大小、原始数据范围和索引地址增加检查；手动映射仍明确拒绝尚未支持的静态 TLS。
- 根据 Hook 0x8e30、0x8f10 恢复消息快照的整数标记解码、UID 指针标记验证、双层变长长度和 UID 内容解码。
- 常驻模块回调或清理回调抛出 C++ 异常时，继续释放引用、更新活跃计数并处理剩余清理任务，随后传播异常。新增专门的异常测试源码。
- 测试宿主启动失败时立即传递错误，防止留下未处理的 Promise 或等待响应直至超时。
- 仓库浏览版源码可从相邻完整 ZIP 校验并恢复 Node SDK；完整 ZIP 自带工具链。
