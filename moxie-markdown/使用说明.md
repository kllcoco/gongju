# 墨写 2.0 · 独立桌面 Markdown 编辑器

完成构建后运行 `Moxie-2.0.2.exe`。不依赖系统 Python，也不需要浏览器。程序与 MCP 共用 `_internal` 运行库，请保留完整文件夹。

## 写作与阅读

- 新建、打开、保存、另存为、最近文档。
- 双栏编辑预览、专注编辑、阅读模式和文字缩放。
- 点击文档大纲会同步定位编辑区和阅读预览，并突出显示目标标题；阅读模式也支持跳转。
- 支持重复标题、下划线式标题和键盘选择。标题与引用提供颜色提示。
- 标题、粗体、斜体、代码、代码块、引用、列表、链接、图片、表格插入。
- 本地图片直接显示，表格使用带边框的单元格布局。
- 查找、替换、全部替换、撤销、重做。
- 回车自动延续列表和缩进。
- HTML 与 PDF 导出，支持中文与基本表格、图片。

## 工具栏与右键语法菜单

中间工具栏提供标题 H1–H6、粗体、斜体、代码、列表、引用、链接、图片、表格，以及“更多语法”。

在左侧编辑区单击鼠标右键，即可展开完整的已支持语法菜单：

- 标题：一级到六级、恢复正文。
- 文字格式：粗体、斜体、粗斜体、删除线、行内代码。
- 列表与任务：无序、有序、未完成任务、已完成任务。
- 引用：普通引用、嵌套引用。
- 链接与图片：普通链接、本地图片、图片语法、引用式链接。
- 代码块：普通、Python、JavaScript、TypeScript、JSON、Shell、SQL、HTML、CSS。
- 其他：表格、分隔线、脚注、定义列表、强制换行、转义字符。

选中文字后右键会保留选区，插入格式作用于选中文本；没有选区时，插入位置为鼠标点击位置。Shift+F10 可在当前光标处打开同一菜单。任务清单和删除线支持预览；任务勾选在 Markdown 源码中修改。代码语言标签用于生成语法，不代表彩色代码高亮。

## 恢复与版本

每约两秒保存一份独立恢复草稿，不自动覆盖原文。异常退出后，重新打开程序会提示恢复，也可以从“文件 → 恢复草稿”选择。

保存已有文件前保留备份；从“文件 → 历史版本”恢复到编辑区，再自行保存。每个文件保留最近 30 个版本。通过“退出”选择不保存会丢弃当前窗口的恢复草稿。

其他程序或 MCP 修改了磁盘文件时，编辑器没有未保存修改会自动更新；有修改时会保留当前内容，并在保存前再次确认。

## 快捷键

Ctrl+N 新建；Ctrl+O 打开；Ctrl+S 保存；Ctrl+Shift+S 另存为；Ctrl+F/H 查找替换；Ctrl+B 粗体；Ctrl+I 斜体；Ctrl+Z 撤销；Ctrl+Y 重做；Ctrl+加号/减号调整文字；Tab 插入四个空格。

## MCP

LLM 可以通过标准 MCP 读取、创建、修改文档，或操作当前编辑区。接入方法见 `MCP接入说明.md` 与 `mcp-config.json`。默认工作目录为 `Documents`，里面附有体验文档。

## 当前边界

本产品为 Markdown 源码编辑与实时预览，尚不支持直接在阅读区排版编辑。暂不支持 LaTeX 数学公式、Mermaid、网络图片自动下载、协同编辑或 Word DOCX 导出。复杂 HTML/CSS 的预览及导出不会完全复现浏览器效果；PDF 使用简洁文档排版。

本文件夹包含完整源代码，便于进一步开发。恢复草稿、偏好与版本数据保存在本程序的 data 文件夹中。
