# 欢迎使用 Markdown 编辑器

写下你的想法，右侧会立即显示排版效果。

## 常用语法

这是 **粗体**、*斜体* 和 `行内代码`。

- 打开其他程序员分享的 Markdown 文件
- 编辑项目说明、学习笔记或开发文档
- 按 **Ctrl + S** 保存

> 文件保存在自己的电脑上，断网也能使用。

## 代码示例

```python
def hello(name):
    return f"你好，{name}！"

print(hello("Markdown"))
```

## 表格

| 文件 | 用途 |
| --- | --- |
| README.md | 项目说明 |
| CHANGELOG.md | 更新记录 |
